# 汉听大字典/行政区划

数据收集自 [中国国家地名信息库](https://dmfw.mca.gov.cn/)。

数据不包含：

- 加格达奇区等非标准建制
- 岑岭县，草湖市
- 港澳台地区

如有需要可以去看看 <https://github.com/mumuy/data_location>，该仓库包含了更多数据。

---

`.short.csv` 是去掉通名部分的版本，也不包含民族名称。

`县级.short.csv` 对名字较长的（民族）旗做了简化。
数据中有单字县/县级市/旗，使用时需结合 `type` 字段恢复。
我们建议对这些单字县应用以下逻辑。

```python
data['name'] += data['type'][-1]
```

当使用上述逻辑恢复省地级的通名时，应注意 `地区`、`自治区`、`特别行政区` 等一般不简称为单字的通名。
