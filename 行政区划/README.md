# 汉听大字典/行政区划

数据收集自 [中国国家地名信息库](https://dmfw.mca.gov.cn/)。

数据不包含：

- 加格达奇区等非标准建制，
- 港澳台地区。

如有需要可以去看看 <https://github.com/montmorill/data_location>，该仓库包含了更多数据。

## 关于 `name` 的格式

`name` 由专名部分（民族部分使用 `|` 标记）与通名部分用 `:` 连接而成，如：

- `北京:市`
  `津市:市`
  `沛:县`
- `清新:区`
  `浦东:新区`
  `矿:区`
  `峰峰:矿区`
  `神农架:林区`
  `六枝:特区`
- `青龙|满族:自治县`
  `威宁|彝族|回族|苗族:自治县`
  `|鄂伦春:自治旗`
  `|鄂温克族:自治旗`

对于团镇合一的（乡级），团名部分与镇名部分用 `/` 连接，如：

```csv
code,name
659009100,四十七:团/老兵:镇
659009101,皮山:农场/昆泉:镇
659009102,一:牧场/昆牧:镇
659009103,二二五:团/玉泉:镇
659009104,二二四:团/玉园:镇
```
