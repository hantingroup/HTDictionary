# 汉听大字典/行政区划

数据收集自 [中国国家地名信息库](https://dmfw.mca.gov.cn/)。

数据不包含：

- 加格达奇区等非标准建制
- 港澳台地区

如有需要可以去看看 <https://github.com/montmorill/data_location>，该仓库包含了更多数据。

## 关于 `.split.csv`

`specific` 为专名部分（民族部分使用 `|` 标记），`generic` 为通名部分，如：

- `芒,市`
  `津市,市`
  `沛,县`
- `清新,区`
  `浦东,新区`
  `矿,区`
  `峰峰,矿区`
  `神农架,林区`
  `六枝,特区`
- `巴里坤|哈萨克,自治县`
  `威宁|彝族|回族|苗族,自治县`
  `|鄂伦春,自治旗`
  `|鄂温克族,自治旗`

对于团镇合一的，团名记录在 `farm`，如：

```csv
parent,specific,generic,farm
659009100,老兵,镇,四十七团
659009101,昆泉,镇,皮山农场
659009102,昆牧,镇,一牧场
659009103,玉泉,镇,二二五团
659009104,玉园,镇,二二四团
```

> [!WARNING]
> 红星二场并不以 `农场` 结尾，其记录如此：
>
> ```csv
> parent,specific,generic,farm
> 659011400,红星二,农场,红星二场
> ```
